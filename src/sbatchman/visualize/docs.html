Make your first plot

Follow these steps in order: query data, check its columns, configure the chart, then render it.

  1. Choose a table and query

    In Schema, expand a table with its arrow. A new tab starts with a basic SELECT * query when a table is available. Edit the SQL in Data source to select the rows and columns you need.

  2. Run the query

    Click Run & show. This checks the query and displays a data preview. The query’s column names then become available in the mapping controls.

  3. Configure the chart

    Choose a plot type, then select an X column and one or more Y columns in Data mappings. Some plot types show extra required fields; for example, a heatmap asks for a Z column.

  4. Render the plot

    Click Run in the top bar. If the result is not what you expect, adjust the SQL or mappings and run it again.

  5. Save your workspace

    Click Export workspace and save the JSON file (plots.json) to the directory from where your ran the visualize command. This way, next time you start the webUI, you will resume from where you left off.

To save the result, choose PNG or SVG in the top bar and click Save image.
